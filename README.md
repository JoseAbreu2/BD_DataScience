### 🚀 Projeto em Destaque: Simulador de Impacto Tributário (Reforma Tributária IVA)

Este projeto demonstra minha capacidade de traduzir um problema de negócio complexo (legislação) em uma solução de dados automatizada.

* **Problema:** A empresa precisava dimensionar o impacto da transição da legislação tributária brasileira (IVA) sobre seu portfólio de produtos (NCMs) em diferentes cenários e localidades.
* **Solução:** Desenvolvi uma automação em **N8N** que consome APIs tributárias para consultar, em lote, 86 NCMs distintos, cruzando-os contra o período de transição (2026-2033) e as 27 capitais brasileiras.
* **Resultado:** Geração de uma base de dados consolidada com **mais de 17.000 linhas**, permitindo uma análise de impacto precisa, rápida e estratégica para o negócio.
